# Fichiers déposés à la racine du site

Tout fichier placé dans ce dossier est recopié tel quel à la racine du site
publié, sans transformation. C'est l'endroit prévu pour les fichiers qu'un
service extérieur exige de trouver à une adresse précise :

- la preuve de propriété demandée par la Google Search Console
  (`google….html`), ou son équivalent chez Bing (`BingSiteAuth.xml`) ;
- le fichier `CNAME` si le site est un jour servi depuis un domaine
  personnalisé ;
- tout autre fichier de convention (`ads.txt`, `security.txt`…).

Ce présent `README.md` est le seul fichier ignoré : il documente le dossier sans
se retrouver publié.

Le générateur n'inspecte pas ces fichiers et le contrôle qualité ne les analyse
pas — ils ne sont ni des pages du recueil ni du contenu éditorial.
